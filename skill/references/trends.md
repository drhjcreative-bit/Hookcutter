# Short-form trend library

Editable knowledge base. Update as formats evolve.

## Core principles

- The first 1.5 seconds decide retention. Cold-open on the single most
  surprising or high-stakes line/frame — never on setup or a slate.
- Show the payoff early, then earn it back (open loop). Don't bury the lede.
- Cut on motion or on the beat. Dead air > 0.4s kills pace on <60s edits.
- Captions are non-optional on mute-first feeds. Big, high-contrast, word-timed.
- One idea per video. If it needs two hooks, it's two videos.
- End on a button: a punchline, a loop back to the hook, or an explicit CTA.

## Hook archetypes (fill the blanks from the actual content)

| Archetype | Template |
|---|---|
| Contrarian | "Everyone tells you {common belief}. They're wrong." |
| Stakes | "I {big action} so you don't have to." |
| Numbered | "{N} {things} that {payoff} in {timeframe}." |
| Curiosity gap | "The real reason {surprising subject} isn't what you think." |
| Callout | "If you {audience behavior}, watch this." |
| Before/After | "This went from {bad state} to {good state}. Here's how." |
| Mistake | "The #1 mistake people make with {topic}." |

## Format templates

**Talking-head fast-cut** — fits talking/mixed · lengths 15/30/45/60
Structure: hook line → jump-cut body → payoff → CTA button.
Pace: remove pauses/filler; avg clip 1.5–3s; zoom-punch on key words.
Captions: karaoke.

**Numbered listicle** — fits talking/mixed · lengths 30/45/60
Structure: numbered hook → point 1 → point 2 → point 3 → recap/CTA.
Pace: one point per beat; on-screen counter; tighten between points.
Captions: karaoke.

**B-roll beat montage** — fits b-roll/gameplay/mixed · lengths 15/30
Structure: cold-open peak → build → drop montage → tag.
Pace: cut on the beat; escalate energy; save the best frame for the drop.
Captions: block.

**Gameplay / screen highlight** — fits gameplay/mixed · lengths 15/30/45
Structure: action-peak cold open → context → second peak → reaction button.
Pace: open on the loudest/most intense peak; speed-ramp in.
Captions: block.

**Extended story / essay** — fits talking/mixed · length extended (90–180s)
Structure: hook → setup → escalation → turn → payoff → reflection/CTA.
Pace: earn the length; re-hook every ~20s with a mini open loop.
Captions: karaoke.

## Hashtag strategy

Mix 2–3 broad reach tags (#fyp #foryou #shorts #reels) with 3–5 niche/topical
tags pulled from the actual subject. Avoid banned/spammy tags. Front-load the
most specific ones.
